# Careerly

Flutter app. Remote: https://github.com/MarcEsteban04/Careerly (private), branch `main`.

## Working rules

1. **Commit and push every finished request to `main`.** When a request is done, commit it and push to `origin/main`; don't leave work only in the local repo. One focused commit per request with a clear message.
2. **No Claude attribution.** Never add `Co-Authored-By: Claude ...` or any Claude Code attribution line to commits or PRs.
3. **Keep the project organized and clean.** Put every file in a logical folder, use consistent naming (`snake_case.dart`), remove dead code and unused files, and don't leave stray files at the repo root.
4. **Act as a senior UI/UX designer.** Every screen should look clean and polished: consistent spacing, typography and color from a shared theme, clear visual hierarchy, accessible contrast and tap targets, and thoughtful empty, loading and error states. Suggest UX improvements when you see them.
